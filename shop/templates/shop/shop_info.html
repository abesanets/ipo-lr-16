Shopex Electronics

Shopex — это высокотехнологичный учебный интернет-магазин цифровой техники и электроники, построенный на связке Django REST Framework + Vanilla JS / Fetch API.

Проект демонстрирует полноценный стек разработки веб-приложений:

• Бэкенд: Реализован на Django 6, предоставляет гибкие представления для каталога товаров, корзины покупателя, системы заказов и API-эндпоинты на базе Django REST Framework с сессионной авторизацией.

• База данных: СУБД PostgreSQL/SQLite для хранения товаров, производителей, категорий, корзин, заказов и ролевых профилей пользователей.

• Фронтенд: Разработан в виде чистого CSS интерфейса с использованием Fetch API для динамической бесшовной загрузки каталога товаров в реальном времени.

• Дополнительно: Реализована отправка электронных писем с сформированными Excel-чеками заказов покупателям, сгенерированными с помощью библиотеки openpyxl.
